\section*{\color{scipostdeepblue}{Abstract}}
\textbf{\boldmath{%
% Write your abstract here.
DRAFT: Non-Markovian quantum dynamics cannot, in general, be specified by a sequence of single-time reduced density matrices alone: multi-time statistics depend on how a system is interrogated and controlled between observations. Process tensors provide an operational description of this temporal structure and admit compact matrix-product-operator representations when temporal correlations are compressible. We present ProcessTensors.jl, an ITensor-native framework in which process tensors are Matrix Product Operators that can be constructed, stored, contracted with physical instruments, and reused for reduced dynamics and multi-time observables. The package extends the ITensors.jl/ITensorMPS.jl ecosystem with explicit Hilbert- and Liouville-space types, system and environment abstractions, instrument schedules, and high-level process-evaluation routines. Small environments can be treated with a dense builder that serves as a reference implementation, while an automated-compression-of-environments (ACE) backend provides a scalable route to multimode environments. We describe the mathematical conventions, software architecture, validation strategy, and representative workflows, and outline the package as an extensible platform for future process-tensor algorithms and characterisation tools. \textbf{[TODO: insert one quantitative headline benchmark result before submission.]}
